# CVPR_2023

集中管理 **CVPR 2023 冠层图** 与 **CVPR 2023 叶面斑块** 相关的公开 GitHub 代码和来源链接。

来源：`开源代码清单(4).md`、`开源代码清单(5).md`。

**统计：** 两份清单共 83 条项目记录，跨方向重复 9 条，按原仓库地址去重后共 **74 个唯一项目**。其中 **46 个**已确认具有再分发许可，安排导入源码；**28 个**目前缺少仓库级许可证，只登记原始链接、暂不公开镜像源码。

> 本仓库以不同文件夹集中收录 GitHub 上游项目，不是官方 GitHub Fork。源码导入为上游默认分支的浅克隆快照，不包含独立上游提交历史。不意味着源码可商业使用、可在任何许可下重新发布或已复现实验。

## 保存原则

- **同一仓库只保存一份**：`FasterNet`、`Torch-Pruning`、`sparsevit`、`MIC`、`ml-mobileone`、`CutLER`、`InternImage`、`ConvNeXt-V2` 和 `BiFormer` 均在两个研究方向复用。
- 每个子目录里的 `SOURCE.md` 记录论文题目、原仓库、许可证、优先查看入口与研究方向。
- 未发现可确认的许可证时，只有 `SOURCE.md`，**没有重新分发上游源码**。如需拷贝须先核实上游版权方许可。
- 带 **NC**、`CC BY-NC-SA`、`CC BY-NC` 的项目**不得用于违反非商业条款的用途**；`NViT` 的许可将用途限制为非商业研究或评估。复制时保留原许可证和署名。
- 源代码仅复制上游默认分支当前的公开快照，可能与 2023 年论文发布时的代码版本不同。
- 模型权重、大型数据、Git LFS 对象、Git Submodule 及超过 GitHub 单文件上传限额的资源可能未完整镜像。请查阅 [导入报告](./import-reports/latest-import.md) 和上游原仓库。
- 本仓库不负责修改用户 Windows 本地目录，代码文件夹名依照原始清单保存。
